            Or use Apple Health instead

            Your Etekcity scale writes to Apple Health. An iPhone Shortcut can send those readings here every morning.

            The link has your token in it: anyone with it can add readings to your account. "New link" cancels the old one.

            Two-action Shortcut
            1. Open Shortcuts, tap +. Add Find Health Samples: type Weight, Sort by Start Date, Latest First, Limit 1.
            2. Add Get Contents of URL: paste your link, set Method to POST, Request Body to File, and choose the Health Samples variable as the file.
            3. Run it once: the reply says "ok":true. Then in the Automation tab add a daily Time of Day that runs it, with "Ask before running" off.

            Want body fat too? Add a second Find Health Samples for Body Fat Percentage and a second Get Contents of URL for it, same link.
