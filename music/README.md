# Music for posts

30-second clips people can add to a post in Cheat Days. Every track is from FreePD.com, which released all its music under CC0 1.0 Universal (a public domain dedication) and closed in 2025; the files were fetched from the Internet Archive's copy (archive.org/details/freepd). `SOURCES.json` records each clip's source address, licence and the checksum of the file it was cut from. `music.json` is the list the app shows.

Rebuild with `python -I design/music_clips.py`.
